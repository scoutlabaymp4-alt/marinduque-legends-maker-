# Marinduque Legends Character Maker

A small, responsive, single-page character maker for students, young residents, and visitors curious about Marinduque culture. It uses tabletop-style character ideas inspired by local places and traditions.

> Archetypes and ability scores are fictional educational demonstration content. They are not authoritative history.

## Open the app

No installation or build step is required. Open the project's root `index.html` in a browser. Keep the related files and folders together so the page can load its stylesheet and JavaScript:

```text
marinduque-legends-maker/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

The root `index.html` is the final app entry point. The HTML links to `css/style.css` and `js/script.js` using relative paths.

## Features

- Create a character with a name, archetype, and Marinduque municipality.
- Roll six fictional ability scores, each from 3 to 18.
- View the character and current scores on a generated character card.
- Use semantic form controls, keyboard interaction, and status announcements.
- View a responsive layout designed to work on narrow screens.

## Project contents

- `index.html`, `css/style.css`, and `js/script.js` — final single-page app.
- `prompt-log.md` — prompt experiments, observations, verification, and reflection for the lab activity.
- `SUBMISSION-CHECKLIST.md` — assignment deliverables and submission status.
- `outputs/` — saved baseline, structured-prompt, few-shot, accessibility-review, and analysis results. These are experiment records; open the root `index.html` for the final app.

## Technology

Plain HTML, CSS, and vanilla JavaScript. There is no backend, database, authentication, build system, or external API.
